AEP Identity Namespace Explained

Learn what an Identity Namespace is in Adobe Experience Platform, how it works with identities, and how it helps create a unified customer profile.

1. What is Identity in AEP?

An identity represents a person, device, account or other entity that can be recognized across different systems.

For example, a customer may interact with a company using:

  • Email address
  • Mobile number
  • Customer ID
  • CRM ID
  • Device ID
Example:
Customer ID = CUST10001
Email = customer@example.com

2. What is an Identity Namespace?

An Identity Namespace provides the context for an identity. It tells AEP what type of identity value it is dealing with.

Identity Value
→
Identity Namespace
→
Identity Context

3. Simple Example

Identity Value Namespace Meaning
john@example.com Email Customer email identity
CUST10001 Customer ID Customer identifier
9876543210 Phone Customer phone identity

4. Real-World Example

Imagine a company that has multiple businesses such as Croma, Tata Motors and Tata Insurance.

The same customer could interact with multiple businesses. Each system may have a different identifier for that customer.

Croma Customer ID
→
Email
→
CRM ID
→
Unified Profile

AEP can use identity information to help connect these interactions into a more complete customer view.

5. Identity vs Identity Namespace

Concept Example
Identity john@example.com
Identity Namespace Email

Think of it this way:

Identity = Value
john@example.com

Namespace = Meaning / Type
Email

6. Identity Graph

The Identity Graph represents relationships between different identities that belong to the same customer or entity.

Email
↔
Customer ID
↔
Phone

These identity relationships can help AEP build a connected understanding of a customer.

7. Why Identity Matters in AEP

  • Helps connect customer interactions.
  • Supports Real-Time Customer Profile.
  • Enables cross-channel customer analysis.
  • Helps unify identities from different systems.
  • Supports segmentation and activation use cases.

8. Interview Questions

Q1. What is an Identity Namespace?

It provides context to an identity value, such as Email, Phone or Customer ID.

Q2. What is the difference between Identity and Namespace?

Identity is the actual value, while the namespace describes the type or context of that value.

Q3. What is an Identity Graph?

It represents relationships between identities associated with an entity or customer.

Q4. Why is identity important for Real-Time Customer Profile?

Identity information helps connect customer data and interactions to customer profiles.

9. Key Takeaway

Remember:

Identity = the actual identifier.

Namespace = the context/type of the identifier.

Identity Graph = relationships between identities.
