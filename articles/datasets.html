AEP Datasets

An AEP Dataset is a storage container used to hold data in Adobe Experience Platform. A dataset is associated with an XDM Schema, which defines the structure of the data.

1. What is a Dataset?

Think of a dataset as a container where actual customer data records are stored. The schema defines what the data should look like, while the dataset stores the data.

Simple example:

Schema → Customer Profile Schema
Dataset → Customer Profile Dataset

Customer ID → CUST10001
Name → Ananya
Email → ananya@example.com
Mobile → 9876543210

2. Schema vs Dataset

Schema Dataset
Defines the structure of data Stores the actual data
Defines fields and data types Contains records
Acts as a blueprint Acts as a data container
Example: Customer ID, Email, Mobile Example: CUST10001, customer@example.com
Schema → Dataset → Data Ingestion → Data Lake

3. Types of Dataset

A dataset is generally created from an XDM schema. The schema determines the kind of data the dataset is designed to hold.

Data Type Purpose Example
Record Data Stores information about entities Customer profile information
Time-Series Data Stores events that happen over time Product view, purchase, login

4. Profile-Enabled Dataset

A dataset can be enabled for Real-Time Customer Profile when the associated schema supports Profile. Data from Profile-enabled datasets can contribute to a unified customer profile.

Example:

Customer Profile Dataset
→ Customer ID
→ Email
→ Mobile
→ Loyalty Tier

Profile Enabled = Yes
Profile Schema → Profile-Enabled Dataset → Real-Time Customer Profile

5. Experience Event Dataset

Experience Event datasets store customer interactions that happen over time. These events can be used to understand customer behavior.

Example:

Customer ID → CUST10001
Event → Product Viewed
Product → LAPTOP123
Timestamp → 2026-09-19T10:30:00Z

6. Tata / Croma Example

Imagine a Tata ecosystem containing Croma, Tata Motors, Tata Insurance and other Tata businesses.

Customer: CUST10001

Croma Dataset → Laptop Purchase
Tata Motors Dataset → SUV Interest
Insurance Dataset → Car Insurance

Email → customer@example.com
Mobile → 9876543210

Different systems can send customer information into different datasets. Identity information can then help AEP connect information belonging to the same customer.

7. Dataset and Data Ingestion

Before data can be stored in a dataset, the incoming data must follow the structure defined by the associated XDM schema.

Source System ↓ Data Ingestion ↓ XDM Schema ↓ Dataset ↓ Data Lake

8. Dataset and Real-Time Customer Profile

When a dataset is enabled for Real-Time Customer Profile and receives appropriate profile or event data, that data can contribute to the unified customer profile.

Source → Schema → Dataset → Identity → Real-Time Customer Profile

12. Interview Question

Question: What is the difference between a schema and a dataset in AEP?

Answer: A schema defines the structure and meaning of the data, while a dataset is the container where records following that schema are stored.

Question: Can multiple datasets use the same schema?

Yes. A schema can be associated with multiple datasets when the same data structure is required for different data collections or use cases.

Question: What is a Profile-enabled dataset?

A Profile-enabled dataset is a dataset configured to contribute eligible data to Real-Time Customer Profile.
