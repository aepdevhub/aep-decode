AEP Fundamentals

Adobe Experience Platform (AEP) is a cloud platform used to collect, organize, unify and activate customer data.

1. What is AEP?

AEP brings customer data from different sources into a centralized platform so organizations can understand and act on customer behavior.

2. Core AEP Components

  • Sandboxes
  • XDM Schemas
  • Datasets
  • Data Ingestion
  • Identity Service
  • Real-Time Customer Profile
  • Segmentation
  • Activation

3. Basic AEP Data Flow

Data Sources → Ingestion → Schema → Dataset → Identity → Real-Time Customer Profile → Segment → Activation

4. Data Lake

AEP stores ingested data in its Data Lake. The data can then be used by different AEP services for analytics, profile creation and activation.

5. Real-Time Customer Profile

Real-Time Customer Profile combines profile attributes and customer events to create a unified view of a customer.

6. Why AEP is Important for Developers

  • Build data ingestion solutions
  • Work with XDM schemas and datasets
  • Configure identity management
  • Use AEP REST APIs
  • Automate AEP operations
  • Integrate AEP with AEM and AJO
