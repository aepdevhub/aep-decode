AEP Identity

Identity is one of the most important concepts in Adobe Experience Platform. It helps AEP understand that different identifiers can belong to the same person, device or business entity.

1. What is an Identity?

An identity represents an identifiable person, device, account or other entity across different systems.

Example customer:

Customer ID → CUST10001
Email → customer@example.com
Mobile → 9876543210
CRM ID → CRM78901

These identifiers may come from different systems, but they can represent the same customer.

2. What is an Identity Namespace?

An Identity Namespace provides context for an identity value. It tells AEP what type of identifier the value represents.

Namespace Identity Value
Email customer@example.com
Phone 9876543210
Customer ID CUST10001
CRM ID CRM78901
Remember:

Identity Value + Identity Namespace = Identity

4. Identity Graph

The Identity Graph represents relationships between identities. It can connect identifiers that are associated with the same customer.

Email
↓ Customer
↑ Customer ID
↑ CRM ID
↑ Mobile

This relationship helps AEP build a more complete understanding of a customer across different systems.

5. Tata / Croma Example

Consider a Tata ecosystem containing Croma, Tata Motors and Tata Insurance. A customer may interact with multiple Tata businesses using different identifiers.

Customer: CUST10001

Croma → customer@example.com
Tata Motors → CRM78901
Tata Insurance → 9876543210

Common Customer ID → CUST10001
Croma + Tata Motors + Tata Insurance ↓ Identity Resolution ↓ Unified Customer Understanding

6. Identity in an XDM Schema

An XDM field can be configured to participate in identity handling. For example, a Customer ID or Email field can be designated as an identity when the data model and use case require it.

Example:

Customer ID
Type → String
Identity → Yes
Identity Namespace → Customer ID

7. Primary Identity

A primary identity can be designated for a record when defining the identity behavior of the schema.

Example:

Customer ID = CUST10001
Namespace = Customer ID
Primary Identity = Yes

8. Identity Resolution

Identity resolution is the process of determining relationships between different identity values so that customer information from different sources can be connected.

Email + Mobile + CRM ID + Customer ID ↓ Identity Resolution ↓ Customer Profile

9. Why Identity is Important in AEP

  • Connects customer information from different systems
  • Supports unified customer profiles
  • Helps connect online and offline interactions
  • Supports customer journey analysis
  • Can support segmentation and activation use cases
  • Helps understand relationships between identifiers

11. Developer View

As an AEP developer, you should understand how identity information moves from source data into XDM, datasets and ultimately customer profiles.

Source Data ↓ XDM Schema ↓ Identity Field ↓ Identity Namespace ↓ Dataset ↓ Identity Graph ↓ Real-Time Customer Profile

12. Interview Questions

What is an identity in AEP?

An identity is an identifier representing a person, device, account or other entity.

What is an identity namespace?

An identity namespace provides context for an identity value, such as Email, Phone or Customer ID.

What is an identity graph?

An identity graph represents relationships between identity values and helps connect identifiers associated with the same entity.

Why is identity important in AEP?

Identity allows data from different sources and systems to be connected when those identifiers represent the same customer or entity.
