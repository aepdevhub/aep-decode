AEP Schemas

An XDM Schema defines how customer data is structured in Adobe Experience Platform (AEP).

1. What is an XDM Schema?

Think of a schema as the blueprint for your data. It tells AEP what fields exist, what type of data they contain, and how that data should be interpreted.

Simple example:

Customer ID → CUST10001
First Name → Rahul
Email → rahul@example.com
Mobile → 9876543210

2. Main Schema Types

Schema Type Purpose Example
Individual Profile Stores customer/profile attributes Name, email, phone, loyalty ID
Experience Event Stores customer interactions/events Product view, purchase, add-to-cart
Custom / Other Used for organization-specific data Business-specific objects

3. XDM Field Groups

Field groups are reusable collections of fields that can be added to a schema.

Example:

Personal Details Field Group
→ First Name
→ Last Name
→ Email
→ Phone

Instead of manually creating every field, you can select an appropriate field group and reuse standardized fields.

4. Data Types

Common XDM data types include:

  • String
  • Integer
  • Boolean
  • Date
  • Date-Time
  • Number
  • Object
  • Array

5. Profile Schema vs Experience Event Schema

Individual Profile Schema

Represents relatively stable information about a customer.

Customer ID = CUST10001
Name = Ananya
Email = ananya@example.com
Loyalty Tier = Gold

Experience Event Schema

Represents something that happened at a particular point in time.

Customer CUST10001 viewed Product ABC123 at 10:30 AM.

6. Identity in a Schema

Identity fields allow AEP to recognize and connect records belonging to the same customer.

Customer ID → CUST10001
Email → ananya@example.com
CRM ID → CRM10001

One of these fields can be configured as an identity depending on the organization's identity strategy.

7. Profile-Enabled Schema

When a schema is enabled for Real-Time Customer Profile, appropriate records can contribute to a unified customer profile.

Schema → Dataset → Profile → Unified Customer View

8. Tata / Croma Example

Imagine a Tata ecosystem containing Croma, Tata Motors, Tata Insurance and other Tata businesses.

Customer: CUST10001

Email: customer@example.com
Mobile: 9876543210
Croma Purchase: Laptop
Tata Motors Interest: SUV
Insurance: Car Insurance

Different systems can provide different customer information. AEP uses schemas, datasets and identity services to organize and connect this information.

9. Schema → Dataset Relationship

A schema defines the structure, while a dataset is where the data records are stored.

XDM Schema ↓ Dataset ↓ Data Ingestion ↓ Profile / Data Lake

11. Interview Question

Question: What is the difference between a schema and a dataset in AEP?

Answer: A schema defines the structure and meaning of the data, while a dataset is the storage container that holds records following that schema.
